Frequently asked questions

Does this preserve formatting?

No, the output is plain text with no fonts, layout, or images — just the readable text content.

Will this work on scanned PDFs?

Only if the scan already has a text layer (e.g. from OCR). A pure image scan has no extractable text.

Is my file uploaded anywhere?

No, text is extracted locally using pdf.js.
