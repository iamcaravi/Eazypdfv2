Frequently asked questions

How do I change the page order?

Drag each page's thumbnail into the position you want before saving the reordered file.

Can I remove pages while reordering?

Reorder Pages keeps every page — use Delete Pages or Organize PDF if you also need to drop some pages while rearranging.

Is my file uploaded anywhere?

No. Reordering happens locally using pdf-lib.
