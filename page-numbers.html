Frequently asked questions

Can I start numbering from a page other than 1?

Yes, set any starting number, which is useful when this file is part of a larger combined document.

Where can page numbers be placed?

Choose from common positions such as bottom-center, bottom-right, or top-right, with a live preview.

Can I exclude the first page, like a cover page?

Yes, numbering options let you skip the cover page while numbering the rest.
